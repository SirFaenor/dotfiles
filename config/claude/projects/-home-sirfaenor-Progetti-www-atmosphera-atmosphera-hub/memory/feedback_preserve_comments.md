Non rimuovere i commenti aggiunti manualmente dall'utente quando editi un file.

**Why:** l'utente li usa come appunti/riferimenti e la rimozione causa perdita di contesto.

**How to apply:** quando usi Edit o Write su un file esistente, preserva tutti i commenti presenti. Se riscrivi un file intero (Write), riporta i commenti che c'erano. Vale per tutti i progetti, non solo atmosphera-hub.
